# Project Roadmap

---

**Sensors:** SHT45, SCD41, SGP40/41, SPS30, BME280, BME680, SDS011
**Readings:** Temperature, Humidity, Pressure, VOC/NOx, CO2, pm0.5/1/2.5/4/10
**Platform:** ESP32

- Implement support for standalone mode or thread-based mesh networking
- Combine multiple sensor readings to estimate:
  - Air Quality Index
  - Occupancy
  - Ventilation efficiency
  - Dew point
- Implement probabilistic models
  - Bayesian filtering
  - Weighted sensor fusion
- Evaluate accuracy against real measurements
